# Workshop #5: Керування аудіокодеком CS43L22 (I2C) та реалізація світломузики

## 📝 Опис проєкту
Метою даної роботи є налаштування взаємодії мікроконтролера STM32 із зовнішнім цифро-аналоговим перетворювачем (ЦАП) **CS43L22** за допомогою шини **I2C**. 

У проєкті реалізовано керування апаратним генератором тонів (**Beep Generator**), що вбудований в аудіочип. Програма автоматично відтворює запрограмовану мелодію, синхронізуючи кожну ноту з відповідним світлодіодом на платі (ефект світломузики). Згідно з алгоритмом, мелодія програється **рівно 3 рази**, після чого відтворення назавжди зупиняється.

## 🛠 Технічні характеристики
* **Мікроконтролер:** STM32F407VGT6.
* **Аудіокодек:** Cirrus Logic CS43L22.
* **Інтерфейси зв'язку:** 
  * **I2C1** (Standard Mode, 100 kHz) — для передачі конфігураційних команд у регістри чипа.
  * **I2S3** (Master Transmit, 16-bit) з використанням **DMA** — для генерації тактового сигналу (Master Clock), необхідного для роботи аудіочипа.
* **Використані піни:**
    * **PB6 / PB9:** I2C1_SCL / I2C1_SDA.
    * **PC7 / PC10 / PC12:** I2S3_MCK / I2S3_SCK / I2S3_SD.
    * **PD4:** Audio Reset (апаратне вмикання чипа).
    * **PD12 - PD15:** Виходи для керування світлодіодами (Green, Orange, Red, Blue).

## ⚙️ Реалізований функціонал
1. **Ініціалізація ЦАП:** Запуск I2S через DMA та базова конфігурація регістрів CS43L22 (Power-up, налаштування гучності).
2. **Програмування частот:** У коді (через `enum`) жорстко задано всі **16 можливих нот**, на які здатен апаратний Beep Generator (регістр `0x1C`).
3. **Світломузика:** Створено універсальну функцію `CS43L22_Beep`, яка одночасно надсилає I2C команду на старт звуку і подає високий рівень на обраний GPIO-пін (світлодіод).
4. **Контроль виконання:** Головний цикл містить лічильник, який обмежує відтворення мелодії до трьох ітерацій.

## 🔍 Аналіз сигналів (Saleae Logic)
Для верифікації апаратної роботи було використано логічний аналізатор. На знятих трейсах зафіксовано:
1.  **I2C Транзакції (Channels 6-7):** Коректне звернення мікроконтролера до базової адреси ЦАП (`0x4A` / `0x94`) та успішний запис байтів у регістри `0x1C` (частота) та `0x1E` (вмикання/вимикання звуку) з підтвердженням `ACK`.
2.  **Синхронізація (Channels 3, 4, 8):** Ідеальний збіг у часі між моментами відправки I2C-команди "Start Beep" та появою високого рівня на відповідних пінах світлодіодів.
3.  **Зупинка алгоритму:** На макро-масштабі трейсу видно рівно три блоки активності I2C, після чого настає повна тиша на шині даних, що доводить правильну роботу лічильника.

## 🎯 Висновки
Під час виконання лабораторної роботи успішно налаштовано інтерфейс I2C для керування аудіокодеком CS43L22 та його вбудованим генератором тонів (Beep Generator). Розроблено додаток, який повністю виконує поставлене завдання: відтворює запрограмовану мелодію рівно три рази із синхронним супроводом світлодіодів (світломузика), після чого автоматично зупиняється. Апаратну та логічну коректність роботи програми стовідсотково підтверджено часовими діаграмами, знятими за допомогою логічного аналізатора Saleae Logic.

## 🚀 Як запустити
1.  Скомпілювати код та прошити мікроконтролер через STM32CubeIDE.
2.  Підключити навушники або динамік до зеленого аудіороз'єму на платі (або слухати через базовий зумер стенда).
3.  Натиснути кнопку **Reset** на платі або **Resume (F8)** у дебагері.
4.  Спостерігати за синхронним світінням діодів та слухати мелодію (зупиниться після 3-го разу).
